这个应用在做什么？What it does

EN: A tiny Express app. GET / renders a guest-list page from an in-memory array; POST / receives the form, pushes the name into the array, then redirects back to /.

中文：一个极简 Express 应用。GET / 用内存数组渲染来宾名单页面； POST / 接收表单、把姓名存入数组，再重定向回 /。

1. 静态文件中间件 Static files

express.static(path.join(__dirname,'public')) maps the public folder to the site root, so /style.css is served automatically.

把 public 目录映射为网站根目录，所以 HTML 里写 href="/style.css" 就能直接取到文件，无需额外路由。

2. 表单解析中间件 Body parser

express.urlencoded({extended:false}) parses application/x-www-form-urlencoded bodies into req.body.

解析表单请求体并填充 req.body。没有它，req.body.guestName 就是 undefined。

3. 顺序很重要 Order matters

Middleware must be registered before the routes that need it. Requests travel through the stack top-to-bottom.

中间件必须写在需要它的路由之前。请求按注册顺序自上而下依次经过，顺序写错就会失效。

4. 内存“数据库” In-memory store

const guests = [] is just an array in RAM. Data disappears whenever the server restarts.

const guests = [] 只是内存里的数组，服务器重启后数据全部丢失（不是真正的持久化数据库）。

5. 模板字符串渲染 Template literal

Back-tick strings `...${value}...` let you build multi-line HTML and inject JavaScript values.

用反引号 `...${变量}...` 拼多行 HTML，并在 ${} 中插入动态数据，比字符串 + 拼接清爽得多。

6. map + join 套路 Array → HTML

guests.map(n => `<li>${n}</li>`).join('') turns an array into one HTML string.

map() 把每个元素变成一段 HTML，join('') 再把数组合并成一个整体字符串（用空字符串作分隔符，避免出现逗号）。

7. PRG 重定向 Post/Redirect/Get

res.redirect('/') sends the browser back with a GET, so refreshing the page does not re-submit the form.

res.redirect('/') 让浏览器重新发起 GET 请求，刷新页面不会重复提交表单，也不会出现“确认重新提交”提示。

8. 居中卡片三件套 CSS centering

max-width + margin: 40px auto + padding = a centred, readable white card.

max-width 限制宽度、margin: 40px auto 实现水平居中、padding 留白，三者组合出居中的白色卡片。

9. name 属性是桥梁 name ↔ req.body

The input's name="guestName" becomes the key req.body.guestName on the server.

表单控件的 name="guestName" 决定了后端用 req.body.guestName 取值，两者必须完全一致。

10. 安全提醒 XSS

User input is injected straight into HTML here, so a name like <script> would execute. Escape output in real apps.

这里直接把用户输入插进 HTML，若输入 <script> 会被执行（XSS）。真实项目必须对输出做转义。

cd quiz1-f26_solution

2. 启动服务器 / Start

In your browser open http://localhost:3000, type a name, press Add Guest, and the list grows after the redirect.
